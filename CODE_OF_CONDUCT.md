# Contributor Covenant Code of Conduct

We are committed to a welcoming, respectful, and harassment-free community for everyone.

Examples of behavior that contribute to a positive environment include using welcoming language, respecting differing viewpoints, accepting constructive criticism, and focusing on what is best for the community.

Examples of unacceptable behavior include harassment, insults, discriminatory language, personal attacks, and publishing private information without consent.

Project maintainers are responsible for clarifying and enforcing these standards. Report concerns privately to the repository maintainers. Reports will be reviewed and handled with discretion.

This policy applies in project spaces and in public spaces when an individual is representing the project.
